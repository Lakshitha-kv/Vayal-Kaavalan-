Vayal Kaavalan: a spray-safety guardrail agent for Tamil Nadu farmers that checks crop, pest and request before any product reaches the farmer -- 83.3% accuracy, 369 ms median, $0.035 per 1,000 decisions

Description (max 512 characters):
Vayal Kaavalan ("Field Guardian") is a Tamil-English agricultural advisory agent for smallholder farmers. Before any spray product is named, SprayGuard fires a single Strands Decider 2B call with three typed questions: is the crop grounded, does the symptom match, and did the farmer ask for a spray? Only when all three pass does a recommendation proceed. Tested on 16 held-out cases: 83.3% accuracy, 369 ms median latency, $0.035 per 1,000 decisions.
